## 2. 実施手順

### 2.1 密度マップからの 3Dモデル生成（人手）

```bash
# 1. 密度 .npy を読み、閾値 0.5 で 2D バイナリ画像を得る
python3 - <<'PY'
import numpy as np
from skimage import measure
import matplotlib.pyplot as plt

dens = np.load("outputs/phase-01/results/cylinder_topology.npy")
mask = (dens > 0.5).astype(np.uint8)

# 最外周の輪郭を取得
contours = measure.find_contours(mask, 0.5)
# 最大輪郭を保持
main = max(contours, key=len)
np.savetxt("cylinder_contour.csv", main, delimiter=",", header="y,x")

plt.figure(figsize=(6,3))
plt.imshow(mask.T, cmap="gray_r")
plt.plot(main[:,0], main[:,1], "r-")
plt.savefig("cylinder_contour_preview.png", dpi=150)
PY
```

### 2.2 CAD での押し出し

1. `cylinder_contour.csv` を CAD ソフト（Fusion 360 / FreeCAD）にインポート
2. スプラインで閉曲線化
3. 厚み 10 mm で押し出し
4. 取り付け穴（M3 × 2、間隔 20 mm）を裏面に追加
5. STL でエクスポート

### 2.3 3Dプリント条件

| 項目 | 推奨値 |
|---|---|
| ノズル径 | 0.4 mm |
| レイヤ高さ | 0.2 mm |
| 充填率 | 30%（グリッド） |
| 壁厚 | 1.2 mm（3 perimeters） |
| ビルドプレート温度 | 40 °C |
| ノズル温度 | 230 °C（TPU 95A） |
| 印刷速度 | 30 mm/s |
| 冷却 | 無効（TPU は冷却弱め推奨） |
| サポート | なし（最適化段階でオーバーハングを避ける） |

### 2.4 把持テスト手順

1. 印刷後に剥離、バリ取り、固定穴確認
2. SMC MHZ2-16D に取り付け（M3 ねじ）
3. テストワーク（実物 or モック）を平置き
4. グリッパーを下降、把持、持ち上げ、10 秒保持、下降、離脱 → これを **1 試行**
5. 10 試行実施、成功数を記録
6. 成功時は追加荷重を 50 g ずつ増やし、落下時点の追加荷重を記録（最大 500 g）

### 2.5 Go/No-Go 判定基準

- **Go**：3 ケース中 **2 ケース以上** で成功率 ≥ 70%（10 試行中 7 成功以上）
- **No-Go**：Go 条件を満たさない場合 → Phase 2 に進む前に設計プロトコル見直し

## 付録 A: 既知の Phase 1 制約

1. **STL 直接出力なし** — 2D 密度 → CAD 押し出しを経由するため、設計意図と実機の
   差分が発生する可能性。Phase 2 で解決。
2. **Heaviside projection 未実装** — 密度分布に中間値が残る。Phase 2 で β スケジュール
   導入予定。
3. **境界条件はハードコード** — `cases.py` に静的に定義。Phase 2 でワーク JSON から
   自動生成に移行。
4. **最小メンバ厚の明示的制約なし** — フィルタ半径 `rmin` による間接制御のみ。
   実機印刷時に 1.5 mm 未満の梁は手動で補強する。
5. **対象範囲は 2D のみ** — 3 次元的な応力/ねじれは評価不能。
