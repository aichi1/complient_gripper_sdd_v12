# GripperForge — 要件定義

## 目的
ワークのCAD/断面形状データから、コンプライアントメカニズム（関節を持たず構造自身の弾性変形で運動する機構）を用いた最適なグリッパーフィンガーを**トポロジー最適化によって自動設計**し、3Dプリント試作〜ゴム型量産へ繋げるエンドツーエンドのワークフローを MVP として構築する。

本リポジトリでは、この MVP を 5 つの SDD フェーズに分解して実装・検証・公開する。

## スコープ（MVP で取り組む範囲）

### 機能的スコープ
- 2D 断面トポロジー最適化エンジン（SIMP 法 + OC 法）の実装
- コンプライアントメカニズム向け目的関数（mutual mean compliance 最大化）の実装
- 密度フィルタ + Heaviside projection によるチェッカーボード・中間密度の抑制
- ワーク断面形状を境界条件として取り込む機構
- 最適化結果の 3D 化（押し出し）と STL エクスポート
- 最低限の Web UI（React）+ バックエンド API（FastAPI）による非同期ジョブ実行
- 実ワーク 3〜5 種類での最適化〜3Dプリント〜把持テストによる定量検証
- 技術発信物（Zenn 記事・デモ動画・OSS リポジトリ）と初期顧客アプローチ計画

### ターゲットドメイン
- 多品種少量生産の工業部品組立・搬送ライン（初期フォーカス：自動車部品 Tier2〜3）
- 平行 2 爪グリッパーボディ（例：SMC MHZ2 系列）への装着を前提

## 非目的（MVP では扱わない）
- 3D ビューアのリッチ表示（2D 密度分布のみ可視化）
- 詳細な接触解析・摩擦シミュレーション
- 材料データベース（初期は代表的な TPU / シリコン / ウレタン材のみ）
- ユーザー認証・課金・マルチテナント
- 3 次元フル 3D 最適化（当面は 2D 断面 + 押し出しで済ませる）
- ソフトグリッパー・真空吸着系との統合
- 既存 CAD システムとのリアルタイム連携（アップロード経由のみ）

## 制約

### 技術的制約
- 計算は単一マシン（CPU）で完結する規模とする（GPU 前提にしない）
- メッシュ解像度は 100×100 〜 300×300 要素程度を想定（計算時間は数分以内）
- エンジンは純粋 Python（NumPy / SciPy sparse）で構築し、外部 FEM ソルバー依存を避ける
- STL 出力は単一のソリッドメッシュとし、サポート材不要な向きでエクスポート

### ビジネス・物理制約
- 試作費用：1 品種あたり数千円以内（3Dプリント費用）
- 設計リードタイム目標：CAD アップロードから設計完了まで数時間以内（MVP では手動トリガで可）
- 3Dプリンタは FDM/TPU を前提（SLA/MJF は外注バックアップ）
- 対応 OS：Linux / macOS を一次ターゲット、Windows は WSL で動作確認

## 成功条件

### MVP 全体
- 実ワーク 5 種類中 4 種類以上で、既製品汎用ジョーと同等以上の把持安定性を定量的に示すこと
- CAD 入力 → 最適化 → STL 出力までの一連のワークフローが Web UI からエラーなく実行できること
- 有償トライアルに進む意思を示す企業 2 社以上を獲得すること（Phase 4 完了時）

### SDD 各フェーズ
- Phase 1: 3 種類以上のワーク形状でトポロジー最適化が収束し、3Dプリント品が設計通り変形して把持できること
- Phase 2: 5 種類以上のワーク形状で再現性のある収束結果が得られ、STL 出力が 3Dプリント可能な品質であること
- Phase 3: ワーク入力 → パラメータ設定 → 最適化実行 → STL ダウンロードが Web UI で一気通貫に動くこと
- Phase 4: 5 実ワーク中 4 以上で既製品汎用ジョー以上の把持安定性を示すこと
- Phase 5: 技術記事・デモ動画公開、OSS リポジトリ公開、顧客アプローチ 3 社以上実施

## 前提（ユーザー確認済み：2026-04-10）
- プロジェクト開始時点では `~/.sdd-knowledge/` に該当カテゴリのスターター・ふりかえりは存在しない（初回プロジェクト）
- 物理検証（3Dプリント・把持テスト）は実機環境で人手実行する必要があり、SDD フェーズ内では手順書・記録テンプレート・結果レポートの形式で成果物化する
- 以降のフェーズで `/re-init-task` による差分追加を想定する（MVP 完成後の製品化フェーズなど）
- **主要開発 OS**：Linux / macOS を一次ターゲット、Windows は WSL2 前提
- **3Dプリンタ**：FDM / TPU 方式を前提（SLA / MJF は外注バックアップ）
- **対象グリッパーボディ**：SMC MHZ2 系列相当の平行 2 爪を想定
- **OSS ライセンス**：**MIT** で公開（Phase 5）
- **CI**：MVP 段階では必須とせず、Phase 5 以降で導入検討
